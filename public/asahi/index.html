Asahi Linux Experience

Posted on Nov 23, 2025

Hello! I got my first Mac and used macOS. I am a tiling window manager fan, so I wanted a layout like it for macOS but it was too complex. So, I installed Linux on it. Crazy, right?

Installation

Firstly, I ran Asahi Install Command and followed the introductions. And something like Calamares popped up and I finished the installation.

After Installation

I tested it a little bit, it’s really awesome. A lot of packages and copr repositories support Asahi, which is so good. I installed Hyprland on it, now it works really good.

But, it’s not %100 stable and battery doesn’t last as much as macOS.

So, I switched back to macOS. macOS is still better for me. But, if I get bored, I’ll try Asahi again and again.
