How to Use Mac

Posted on Dec 14, 2025

Hello! You bought a Mac and now you are looking to screen without knowing anything? I got you! Today you’ll learn how to use macOS.

What is Dock and Menubar?

Dock is bottom line which you have your apps. Menubar is top bar which has Apple logo, you can control apps here unlike Windows.

In Windows, these bars are merged into one but in macOS, they are seperated.

How to launch apps?

To launch apps, we have two options.

Spotlight

Spotlight is like KRunner on Linux, search menu on Windows. You can access it by pressing ⌘Space or just F4. Just search a file, app and it will open it.

You can use Raycast if Spotlight doesn’t meet your requirements.

Launchpad

Launchpad is start menu of macOS. You can find it in Dock. It has Applications on it, you can arrange them like your iPhone.

Software Updates

Open System Settings app and you will see Software Update Available text if it’s available.

How to install applications

Regular Way (easiest)

Just open web browser, go to app’s website and download .dmg file (if it’s .pkg, just open it and install it like Windows). Open it and move app icon to Applications. You can eject disk image by moving it to Trash bin in your dock.

Advanced Way (Homebrew)

First of all, go to brew.sh website and run that command on your terminal. After that, follow introductions. And, type brew install raycast on your terminal and run Raycast. Follow introductions and finish installation. Then, open Raycast and type Store. Enter it, search Homebrew and install that extension.

To install apps, just open Raycast and search for Search. Type app name, find it, press enter twice. You can assign shortcut for it in Raycast settings.
